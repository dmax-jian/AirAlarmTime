# Повітряна тривога

**AirAlarmTime** — Android-додаток для обліку часу повітряних тривог.

## Можливості

- запис часу початку та закінчення повітряної тривоги;
- кілька тривог протягом одного дня;
- підрахунок часу тривог за день;
- підрахунок часу тривог за поточний місяць;
- перегляд історії записів;
- видалення окремих записів;
- видалення записів за поточний місяць;
- збереження даних на пристрої.

## Встановлення

Для встановлення на Android завантажте **APK-файл** зі сторінки [Releases](../../releases).

Після завантаження APK відкрийте його на Android-пристрої та підтвердьте встановлення.

## Версія

**v1.0.0**

Перший опублікований реліз AirAlarmTime.

## Файли

- **APK** — для безпосереднього встановлення на Android.
- **AAB** — пакет для можливого майбутнього використання в Google Play.
